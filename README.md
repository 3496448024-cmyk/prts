# PRTS 终端卡片 · 明日方舟风格

SillyTavern 用的明日方舟（Arknights）风格干员档案录入卡片，单文件、零依赖。

## 使用

在线预览：**https://3496448024-cmyk.github.io/prts/prts.html**

- 直接下载 `prts.html`，在 SillyTavern 里作为卡片导入即可
- 可选：把 `bgm.mp3` 放在同目录作为背景音乐（没有则静默跳过）

## 网址参数

| 参数 | 作用 |
|---|---|
| `?fast=1` | 极速模式：跳过全部动画，直接进入功能 |
| `?mute` | 静音（关闭音效） |
| `?sfx=0` | 同上，关闭音效 |

## 功能

- 启动动画（冷开场 + 罗德岛徽记 + 球体 + 终端日志），**每段都可用 ESC 或右上角按钮跳过**
- 身份验证：普通验证 / **最高权限登录**（自动填入博士预设）
- 干员档案录入：姓名、性别、种族、源石技艺、过往经历、额外补充（末项可留空）
- **六维属性面板**：物理强度 / 战场机动 / 生理耐受 / 战术规划 / 战斗技巧 / 源石技艺适应性
- 剧情切入点 + 降临地区（双列）与降临点选择
- 高级警报确认 → 生成完整档案，一键复制回酒馆
- 进度自动存档（刷新或误关页面不丢已填内容）

## 操作

- **ESC**：跳过当前动画 / 关闭警报 / 返回上一层
- 单行输入按 **Enter** 继续；多行输入按 **Ctrl+Enter**（或 Mac 的 **Cmd+Enter**）继续
- 顶部右侧 ♪ 可开关背景音乐
